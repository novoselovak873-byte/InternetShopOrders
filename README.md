## Предметная область

Система «Учёт заказов в интернет-магазине» предназначена для хранения и обработки информации о заказах, товарах, зарегистрированных клиентах, оплате и доставке.

Система автоматизирует процесс обработки заказов в базе данных: от момента ручной регистрации нового клиента менеджером и оформления заказа через сайт до автоматического изменения электронных статусов при доставке и фиксации прибыли.

### Основные объекты системы

| Объект | Описание |
|---|---|
| **Заказ** | ID, дата оформления, привязка к ID клиента, список товаров, итоговая сумма, способ оплаты, текущий статус, дата доставки |
| **Товар** | ID, наименование, категория, цена, доступный остаток на складе |
| **Клиент** | ID, ФИО, контактные данные, адрес доставки, учётная запись, история заказов |
| **Менеджер** | Сотрудник, выполняющий регистрацию клиентов, обработку заказов и отчётность |
| **Склад** | Подсистема учёта наличия товаров, резервирования и сборки |
| **Служба доставки** | Подсистема, передающая в БД статус исполнения |
| **Оплата** | Способ расчёта (онлайн или при получении), статус платежа |

### Связи между объектами

- Один менеджер может внести в базу данных несколько клиентов.
- Один клиент может оформить несколько заказов.
- Один заказ может содержать несколько товаров.
- Каждый заказ относится к определённому клиенту, менеджеру и способу оплаты.

---

## Пользователи системы

| Роль | Возможности |
|---|---|
| **Клиент** | Оформление заказов, оплата, отслеживание статуса, отмена заказов, просмотр истории |
| **Менеджер** | Регистрация новых клиентов, обработка заказов, фиксация прибыли, ведение отчётности |
| **Склад** | Проверка наличия товара, бронирование, сборка и упаковка, передача в доставку, оформление возврата |
| **Служба доставки** | Доставка заказа клиенту |

---

## Функции системы

1. Регистрация клиента менеджером в базе данных
2. Ввод данных о заказе
3. Авторизация пользователя
4. Проверка данных
5. Проверка наличия товара на складе
6. Регистрация оплаты
7. Сохранение заказа в базе данных
8. Сборка и отправка заказа
9. Формирование отчёта
