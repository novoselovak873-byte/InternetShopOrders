## Предметная область

Система «Учёт заказов в интернет-магазине» предназначена для хранения и обработки информации о заказах, товарах, клиентах, оплате и доставке.

### Основные объекты

- Заказ — ID, дата, клиент, список товаров, сумма, способ оплаты, статус
- Товар — ID, наименование, категория, цена, остаток
- Клиент — ID, ФИО, контакты, адрес доставки
- Менеджер — регистрирует клиентов, обрабатывает заказы, ведёт отчётность
- Склад — наличие товаров, бронирование, сборка, упаковка
- Служба доставки — доставка заказа клиенту
- Оплата — онлайн или при получении

### Пользователи системы

| Роль | Возможности |
|---|---|
| Клиент | Оформление, оплата, отслеживание, отмена заказов |
| Менеджер | Регистрация клиентов, обработка заказов, отчётность |
| Склад | Наличие, бронирование, сборка, возврат |
| Служба доставки | Доставка заказа клиенту |
