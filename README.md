# Учёт заказов в интернет-магазине

Лабораторная работа №1 по дисциплине «Проектирование информационных систем».

**Выполнила:** студентка группы 26-ИВТ-4-2 Новоселова Карина Сергеевна

## Описание проекта

Информационная система «Учёт заказов в интернет-магазине» предназначена для хранения и обработки информации о заказах, товарах, клиентах, оплате и доставке.

## Стек технологий

- **Язык:** Python 3.11+
- **Библиотеки:** (укажи по мере появления — например, `sqlite3`, `tkinter`, `flask` и т.п.)
- **СУБД:** SQLite
- **Диаграммы:** PlantUML

## Предметная область

Система автоматизирует процесс оформления и обработки заказов: от оформления на сайте до вручения клиенту и фиксации прибыли.

### Основные объекты
- Заказ
- Товар
- Клиент
- Менеджер
- Склад
- Служба доставки
- Оплата

### Пользователи и роли
- **Клиент** — оформление, оплата, отслеживание, отмена заказов
- **Менеджер** — обработка заказов, отчётность, фиксация прибыли
- **Склад** — проверка наличия, бронирование, сборка, упаковка, возврат
- **Служба доставки** — доставка заказа клиенту
